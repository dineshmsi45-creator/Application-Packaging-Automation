# Application Packaging Automation

## Project Overview
This project focuses on automating Windows application packaging and deployment processes.

## Technologies
- PowerShell
- PSADT
- Git
- GitHub
- GitHub Actions
- Pester
- Jenkins

## Project Objectives
1. Automate application installation.
2. Automate application uninstallation.
3. Validate application detection.
4. Automate packaging processes.
5. Generate deployment artifacts.
6. Integrate CI/CD pipelines.
